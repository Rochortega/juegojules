# Asset Manifest (32px Edition)

To replace the placeholders with your own pixel art, create 32x32 PNG images with the following filenames and place them in `assets/sprites/`.

| Filename | Description | Dimensions | Notes |
| :--- | :--- | :--- | :--- |
| `player_idle.png` | Player Standing | 32x32 | |
| `player_run_0.png` | Player Running (Frame 1) | 32x32 | |
| `player_run_1.png` | Player Running (Frame 2) | 32x32 | |
| `player_jump.png` | Player Jumping | 32x32 | |
| `tile_ground.png` | Ground Block | 32x32 | Solid wall/floor |
| `tile_brick.png` | Breakable Brick | 32x32 | Breaks when hit from below |
| `tile_goal.png` | Goal/Flag | 32x32 | End of level |
| `tile_coin.png` | Coin | 32x32 | Floating collectible |
| `enemy.png` | Ground Enemy | 32x32 | Patrolling Goomba-like |
| `enemy_bat.png` | Flying Bat | 32x32 | Sine wave flight |
| `enemy_boss.png` | Boss/King | 32x32 | Stronger enemy |
| `item_potion.png` | Health Potion | 32x32 | Restores 1 heart |
| `ui_heart.png` | HUD Heart | 32x32 | Life indicator |

**Note:** The game engine now renders natively at 640x480. Tiles are 32x32 pixels.
