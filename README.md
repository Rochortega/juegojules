# Retro Platformer

A pixel-art platformer game made with Pygame.

## Controls

### PC (Keyboard)
*   **Arrow Keys**: Move Left/Right
*   **Space**: Jump
*   **Esc**: Quit

### Anbernic RG40XX V (Gamepad)
*   **D-Pad / Joystick**: Move
*   **A / B Button**: Jump

## Installation & Running

### PC
1.  Install Python 3 and Pygame:
    ```bash
    pip install pygame
    ```
2.  Run the game:
    ```bash
    python main.py
    ```

### Anbernic RG40XX V
1.  Copy this entire folder to your device (e.g., in `roms/ports` or `ports`).
2.  The file `Game.pygame` is the entry point. You may need to launch it via your device's file manager or PortMaster interface.
    *   If your system uses a specific launcher script, you might need to point it to `main.py`.
    *   If you need to rename the main file, `Game.pygame` is identical to `main.py`.
